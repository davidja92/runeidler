RUNIC IDLE — GITHUB REPOSITORY

Upload these files/folders to your repository. In Settings > Pages, select main and /docs. Read GITHUB-SETUP.md for the shared friend/highscore backend. The game works without that backend; shared social features require its deployment and the API URL in docs/config.js.

Magic uses pure essence you mine, crafted runes and per-fight spell costs. There are 18 fish, 20 spells, 15 rune types, 157 activities and 162 items. Existing version-1 saves import through the game menu.

No personal saves, browser keys, credentials or local databases are included.
